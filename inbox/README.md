# Inbox

Drop course notes and materials here in any format:

- Photos of handwriting (`.jpg`, `.png`, `.heic`, …)
- Scans / PDFs
- Typed notes (`.md`, `.txt`)
- Chat exports, voice-memo transcripts
- Mixed batches in a subfolder

Optional helpers (any of these help the agent):

- Put the author’s name in the filename, e.g. `2026-09-23-maria-harbor.jpg`
- Add a short `meta.md` next to the files with author, date received, and session if known
- Use a subfolder per packet, e.g. `inbox/2026-09-26-latin-quarter-anna/`

Then ask the agent to **process the inbox** (or just continue the chat after dumping files). The agent will:

1. File originals under `assets/sources/` and create a `_sources/` entry (as received, with author)
2. For photos/scans/etc., write a `transcription.md` next to the originals
3. Update the relevant session and/or curriculum pages with compiled notes and citations
4. Clear the processed items from this folder

Do not put compiled prose here — that belongs on session/place pages after sourcing.
